## 3. Холодный старт на устройстве

```
adb install -r -d build/app/outputs/flutter-apk/app-debug.apk
adb shell am force-stop best.app.lombardspb
adb logcat -c
adb shell am start -n best.app.lombardspb/.MainActivity
# подожди ~15 сек
adb logcat -d -v time | grep -E "flutter \(" | grep -E "AppLog|PushService"
```

Ожидаемая последовательность в логе (ключевое):

```
[AppLog] app_start {session: ...}
[AppLog] net {online: true, ...}
[PushService] permission: authorized
[PushService] token acquired on attempt 0: ...(len=142..205)
[AppLog] token_ok {attempt: 0, ...}
[AppLog] bind_status {server_bound: true, push_enabled: true, local_verified: true}
[PushService] token sent to server: HTTP 200
[AppLog] token_sent {http: 200, has_user: true}
[AppLog] inbox_sync {got: N, added: M, last_id: ...}
```

- [ ] `app_start` есть.
- [ ] `token acquired on attempt 0` (или ≤ 2). Если `token_giveup` — **стоп**,
      разбираться (см. `fcm-log-view.php`).
- [ ] `token sent to server: HTTP 200`.
- [ ] `bind_status` с `server_bound: true` (для устройства с привязанным номером).
- [ ] `inbox_sync` отработал (без `inbox_sync_fail`).
- [ ] В логе **нет** строк с `error` / `_fail` / `exception` от нашего кода
      (`grep -E "flutter.*(error|fail|exception)"` — пусто).
- [ ] `WorkManager initialized` присутствует (строка `WM-WrkMgrInitializer`).

## 8. Как дописывать тесты

Когда нашёл баг или добавил фичу — сначала **тест**, потом фикс.

| Что тестируешь | Куда класть | Движок |
|---|---|---|
| чистая функция (без сети/диска/UI) | `test/pure/*_test.dart`, логику — в `lib/services/push_logic.dart` | `dart test test/pure` |
| сервис с SharedPreferences/HTTP | `test/*_test.dart`, HTTP через `MockClient` и `*.httpClient`, префы через `SharedPreferences.setMockInitialValues` | `flutter test` |
| поведение экрана | `test/<screen>_test.dart`, `testWidgets` + `pumpAndSettle` | `flutter test` |
| ручной сценарий на устройстве | раздел выше в этом файле + строка в разделе 7 | руками |
| серверная чистая логика | `lombard-server/tests/run.php` | `php tests/run.php` |
| живой эндпоинт отвечает | `lombard-server/tests/smoke.sh` | `bash tests/smoke.sh` |

Тестовые швы уже есть: `AppLog.httpClient`, `PushService.httpClient`,
`AppLog.resetForTest()`, `PushService.resetForTest()`,
`PushService.debugHandleData(...)`, `PushService.debugSendAck(...)`.

Пример: поймал баг в разборе ответа `bind-status.php` →
1) добавь кейс в `test/push_service_test.dart` группа `reconcileBindState`
   (через `MockClient` верни проблемное тело), убедись что падает;
2) почини `reconcileBindState`;
3) тест зелёный → в этот чек-лист строку в раздел 7.
